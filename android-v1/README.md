# Composition Lab Android V1

Schlanke Android-Hülle für Composition Lab. Die App öffnet die veröffentlichte Composition-Lab-Webanwendung in einer WebView ohne Chrome-Adress- oder Tab-Leiste.

## Bauen

Das Projekt kann mit Android Studio geöffnet und als APK gebaut werden. Für einen automatischen APK-Build ist zusätzlich ein Gradle-Wrapper bzw. ein GitHub-Actions-Build vorgesehen.

App-ID: `de.wibem.compositionlab`
Version: 1.0
